# Pixel Store — autenticación real

Node.js 18+. Ejecuta `npm install` y `npm start`, luego abre http://localhost:3000.

Las cuentas creadas en registrar.html se guardan en data/users.json con contraseña hasheada. El carrito y las páginas iniciadas requieren sesión.

Para recuperación por Gmail, copia .env.example a .env y configura una contraseña de aplicación de Gmail. Google/Discord OAuth se puede añadir con sus credenciales de desarrollador sin cambiar el diseño.
